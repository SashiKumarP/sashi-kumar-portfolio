# Achievements Page Update

Added a dedicated `AchievementsPage` to the existing React portfolio without replacing the current pages.

## Navigation changes
- The `Achievement` item in the About menu now opens the new Achievements page.
- The existing `View Certificates` CTA on the home page opens the same page.
- The page has a Back button that returns to Home.

## New page behavior
- Scroll-driven certificate hero mosaic inspired by the supplied target site.
- Certificate cards animate from scattered positions into an organized archive.
- Search, category filtering, and newest/oldest sorting.
- Click any credential to open the original PDF in a modal.
- Responsive card grid and hover/reveal animations.

## Uploaded documents
The page includes the supplied certificate/internship/education documents and lightweight first-page thumbnail renders. Identity documents such as Aadhaar, passport, OBC certificate, LORs, memos, and photographs were intentionally not published into the public certificate archive.
